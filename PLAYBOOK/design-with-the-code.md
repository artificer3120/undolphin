# Design with the code

The operator's rule for this lab: design travels with the code.

- **`DESIGN\unDolphin App.dc.html`** — the design mockup, moved in from the studio3120 store 2026-07-21. The reference comp for the surface's look: dark panel-and-rail layout, Archivo + JetBrains Mono, red accent (`#b81414`), dot-grid main field.
- **The reference corpus** stays in the studio3120 store — resolve by marker `undolphin_root` (never a hard path). ~60 collected screenshots and captures of surfaces the operator likes, plus the project-history doc.
- The live UI (`CODE\static\index.html`) implements the mockup's system; a fuller pass applying the reference corpus sits in [[the-open-build-queue|the open build queue]].

When the look changes: change the mockup or pull from the reference corpus first, then implement — the DESIGN folder stays the stated intent, the static folder stays the implementation.
